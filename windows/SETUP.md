# BÉPO

Download bépo keyboard: https://bepo.fr/wiki/Windows
Change default keyboard: Settings>Time & Languages>Typing>Français (options linguistiques)>Claviers
Remove Ctrl+Shift changing keyboard: Settings>Time & Languages>Typing>Advanced keyboard settings>Input Language Hot Keys>Modify>Not assigned
